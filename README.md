## Descripción
Proyecto sencillo desarrollado para registrar los datos básicos de un estudiante.

## Objetivo
Practicar la documentación de un proyecto utilizando Markdown.

## Funciones principales
- Solicitar el nombre del estudiante.
- Solicitar la carrera.
- Solicitar el semestre.
- Mostrar los datos registrados.

## Requisitos
- Python instalado.
- Visual Studio Code o una terminal.

## Ejecución

### Windows

Abrir una terminal en la carpeta del proyecto y ejecutar 
powershell

python sistema_estudiantes.py

### Linux

Abrir una terminal en la carpeta del proyecto y ejecutar
bash

 python3 sistema_estudiantes.py
