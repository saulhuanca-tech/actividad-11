# Manual Técnico

## 1. Descripción técnica
El proyecto es una aplicación sencilla ejecutada desde consola.

## 2. Tecnología utilizada
- Python.

## 3. Requisitos
- Python instalado.
- Editor de código o terminal.

## 4. Estructura del proyecto
- README.md: presentación general del proyecto.
- sistema_estudiantes.py: programa principal.
- docs: carpeta de documentación.
- manual-usuario.md: instrucciones para el usuario.
- manual-tecnico.md: información técnica.

## 5. Preparación
1. Guardar todos los archivos dentro de la carpeta del proyecto.
2. Verificar que Python esté instalado.
3. Abrir la carpeta en Visual Studio Code.

## 6. Ejecución
Abrir la terminal y ejecutar sistema_estudiantes.py.

## 7. Funcionamiento
El programa solicita nombre, carrera y semestre mediante teclado y posteriormente muestra los datos ingresados.
