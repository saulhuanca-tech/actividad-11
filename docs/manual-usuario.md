# Manual de Usuario

## 1. Propósito
Este manual explica cómo utilizar el Sistema de Registro de Estudiantes.

TEMA 2 - MARKDOWN - DOCUMENTACIÓN TÉCNICA

## 2. Inicio
1. Abrir el proyecto.
2. Ejecutar el archivo sistema_estudiantes.py.
3. Esperar que aparezca el mensaje del sistema.

## 3. Registrar un estudiante
1. Escribir el nombre del estudiante.
2. Escribir la carrera.
3. Escribir el semestre.
4. Revisar los datos mostrados al finalizar.

## 4. Resultado esperado
El sistema mostrará el nombre, la carrera y el semestre ingresado.

## 5. Problemas comunes
- Si el programa no inicia, verificar que Python esté instalado.
- Si un dato fue escrito incorrectamente, volver a ejecutar el programa.
